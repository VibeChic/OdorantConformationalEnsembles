# Conformer pipeline

There is no separate package here: conformer generation is implemented in the
`p3` package and is driven by two modules plus the external `xtb` binary.

| Stage | Where | What it does |
| :--- | :--- | :--- |
| Embedding | `p3/conformer_features.py` | RDKit `ETKDGv3` (500 seeds, hybrid search, 50% torsional Monte Carlo) + NAGL AM1-BCC charges |
| Force-field relaxation | `p3/conformer_features.py` | OpenFF Sage 2.2.1 / OpenMM minimisation |
| Clustering | `p3/observables.py` | Symmetry-aware heavy-atom BestRMS (Butina), rotor-adaptive thresholds (0.30 / 0.50 / 0.85 / 1.25 Å) |
| Quantum chemistry | external `xtb 6.7.1 --ohess` | Tight optimisation, numerical Hessian, quasi-RRHO thermochemistry at 300 K |
| Post-processing | `p3/observables.py` | Boltzmann populations, `S_conf`, `N_eff`, geometric observables |

Minimal smoke test (10 molecules from a local SDF, requires `xtb` on `PATH`):

```bash
python -c "import p3.conformer_features as cf; print(cf.__doc__)"
```

The 106,526 production geometries are distributed (CC BY 4.0) in the
QH-Odor-1821 Zenodo record rather than re-generated by users.
